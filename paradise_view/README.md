# Paradise View — website foundation

A responsive tourism campaign website built with separate HTML, CSS and JavaScript files. The design follows the approved obsidian black, jade emerald and antique gold direction.

## Preview
Open `index.html` in a modern browser. An internet connection is required for Google Fonts and remote image assets.

## Before public launch
- Confirm the exact destination scope and replace all illustrative images with location-verified photographs that you own or have permission to use.
- Replace the phoenix placeholder asset in `assets/phoenix-gold.png` with a properly transparent, cleaned-up version of the supplied logo artwork.
- Add verified business listings, real contact information, opening hours, accessibility information and official booking links.
- Connect the enquiry form to a secure backend or form service; it does not currently send or store data.
- Add real privacy, cookie, terms and accessibility pages, HTTPS hosting, analytics with appropriate consent, and a custom 404 page.
- Check links, responsive layouts, image licensing, accessibility and SEO metadata before launch.

## Current interactions
- Responsive mobile navigation
- Experience search and category filtering
- Search overlay and keyboard escape handling
- Expandable travel-guide FAQs
- Contact form validation preview (not connected to a server)
